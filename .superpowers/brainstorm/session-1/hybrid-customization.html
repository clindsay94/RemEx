The "Hybrid" Workflow

  1. User picks a Base Preset (e.g., Cyber-NOC). All resources load from that preset.
  2. An Advanced Panel exposes specific sliders that override individual DynamicResource values in App.axaml.
  3. Users can save their tweaks as a Custom Profile.
